# 媒體下載器 下載

Android App：內建瀏覽器，偵測網頁上的圖片和影片（含 HLS 串流）並下載到手機相簿。這裡只放安裝檔。

## 下載

👉 **[下載最新版 APK](https://github.com/markgameuse/MediaDownloader-releases/releases/latest)**（點進去後，在 Assets 底下按 `MediaDownloader-x.x.x.apk`）

支援 Android 8.0 以上。

## 安裝

1. 下載 APK 並點開安裝。如果跳出「不明來源」的提示，就照畫面允許。
2. Google Play 保護機制可能提示「建議掃描應用程式」，可以選「掃描」讓 Google 檢查，或在「更多詳細資料」裡選擇直接安裝。

## 更新

App 每次開啟、以及每天背景都會檢查這裡有沒有新版本。有新版時會跳出通知，按「下載」會用瀏覽器下載新版 APK，
下載完成後點開安裝即可。下載紀錄和設定都會保留。

> 1.0.0 安裝時可能出現「此應用程式可能有害」的警告，1.0.1 起已移除最可能造成警告的權限。已安裝 1.0.0 的話，直接下載 1.0.1 覆蓋安裝即可。

## 使用

1. 在 App 裡開網頁（網址列可以直接搜尋）。
2. 偵測到圖片或影片時，右下角會出現「圖片 N · 影片 N」按鈕，點開後勾選要下載的項目。
3. 串流影片可以選畫質（預設最高）。下載進度在通知列和「下載紀錄」裡。
4. 檔案存到相簿的 `Pictures/媒體下載器`、`Movies/媒體下載器`，可以在設定裡改資料夾。

有 DRM 保護的影片、加密串流和直播無法下載。請只下載你有權使用的內容，並遵守著作權規定。

## 安全性

- App 會連線到你在內建瀏覽器開啟的網站，以及這個 repo 的 GitHub 頁面（檢查和下載更新）。
- App 只會從這個 repo 檢查更新；不會自己下載或安裝 APK，新版由瀏覽器下載、你自己點開安裝（App 沒有「安裝其他應用程式」權限）。
- 沒有廣告、追蹤或分析套件；下載紀錄只存在手機上。
